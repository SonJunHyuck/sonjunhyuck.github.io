# 하이라이트 글

공통 원칙은 [AGENTS.md](../../../AGENTS.md)를 따른다.

- 글 선별·요약·어조·날짜·사진·레터링: [writing.md](references/writing.md)
- 데이터 형식·카드·썸네일·미리보기·불러오기: [하이라이트 사양](../../../docs/drafts/highlights-spec.md)

하이라이트는 섹션 하나 분량의 짧은 단위다. 원본은 (1) Notion 노트 데이터베이스의 공개된 개발 노트(노트 하나가 하이라이트 하나, Notion 원본은 읽기만 한다)와 (2) 프로젝트 상세의 섹션(`source`로 원본을 공유)이다. 프로젝트로 묶일 작업은 `project`를 연결해 두고, 나중에 모아 프로젝트 상세로 만든다. 2026-11-06 피드를 하이라이트로 흡수했다.
