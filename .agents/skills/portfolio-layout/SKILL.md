# 공통 레이아웃

프로필을 기준으로 모든 페이지의 폭과 읽는 흐름을 일관되게 유지한다.

- 변경 전에 [layout.md](references/layout.md)와 대상 화면의 공통 스타일 사용 여부를 확인한다.
- 콘텐츠 및 자연 줄바꿈 정책은 [AGENTS.md](../../../AGENTS.md)를 따른다.
- 구현 위임은 AGENTS.md의 모델 규칙을 따른다. 구현 담당자는 같은 작업을 재위임하지 않는다.
- 화면 변경 후 데스크톱·모바일에서 폭과 정렬, Light·Dark 색상과 대비, 이미지 비율·잘림·넘침, 링크·키보드 조작·포커스를 확인한다.
- 문서만 수정한 경우 화면 검증을 요구하지 않는다. 수행한 검증과 확인하지 못한 항목을 보고한다.
