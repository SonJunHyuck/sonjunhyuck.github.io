# 공통 레이아웃

공통 정책과 검증 필요 여부는 [AGENTS.md](../../../AGENTS.md)를 따른다. 의미를 유지한 문구·오탈자 수정에는 이 스킬을 추가 적용하지 않는다.

[layout.md](references/layout.md)에서 대상 절만 읽는다.
- 폭·배치·구분선: ‘폭과 흐름’
- 테마·색상: ‘색상 역할’
- 화면 확인 방법: ‘화면 검증 범위’
- 메뉴·상세 상단: 해당 절

실제 수치·색상이 필요할 때 공통 스타일의 해당 선언을 확인한다. 프로젝트 목록과 카드 구성은 [목록 매뉴얼](../portfolio-project/references/list.md)을 참조한다.
