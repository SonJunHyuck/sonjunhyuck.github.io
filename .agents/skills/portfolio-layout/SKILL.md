# 공통 레이아웃

프로필을 기준으로 모든 페이지의 폭과 읽는 흐름을 일관되게 유지한다.

- 콘텐츠·레이아웃 정책, 구현 위임과 검증 여부는 [AGENTS.md](../../../AGENTS.md)를 따른다. 구현 담당자는 같은 작업을 재위임하지 않는다.
- [layout.md](references/layout.md)는 해당 절만 읽는다: 폭·배치·반응형은 ‘폭과 흐름’, 테마·색상은 ‘색상 역할’, 필요한 화면 검증은 ‘화면 검증 범위’.
- 실제 수치·색상이 필요할 때만 대상의 공통 스타일 선언을 확인한다.
- 의미를 유지한 문구·오탈자 수정만으로 이 스킬을 추가 적용하지 않는다.
