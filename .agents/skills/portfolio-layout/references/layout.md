# 레이아웃 기준

실제 수치와 색상의 단일 원본은 [global.css](../../../../src/styles/global.css)다. 값이 필요할 때 해당 선언만 확인한다. 공통 폭과 예외 정책은 [AGENTS.md](../../../../AGENTS.md)를 따른다.

## 폭과 흐름

- 공통 폭은 `--content-width`, 좌우 여백과 반응형 분기는 기존 공통 스타일을 재사용한다.
- 제목·본문·캡션의 타이포그래피와 섹션 간격은 기존 공통 스타일을 재사용한다.
- 자연 줄바꿈과 예외 합의 기준은 AGENTS.md를 따른다.

## 색상 역할

Light는 Apple, Dark는 Spotify를 참고한 이 사이트의 팔레트다.

| 역할·변수 | 사용 |
|---|---|
| `--paper` | 페이지 바탕 |
| `--ink` | 제목과 주요 글자 |
| `--accent` | 링크·핵심 강조·선택 상태 |
| `--muted` | 설명·날짜·메타데이터 |
| `--surface` | 카드·컨트롤 배경 |

- 본문·버튼·배지·포커스는 CSS의 해당 의미별 변수를 쓴다. 강조색을 모든 버튼 글자에 일괄 적용하지 않는다.
- 버튼은 `--button-bg`와 `--button-text`, 표면 위 강조 글자는 `--accent-ink`, 포커스는 `--focus`처럼 기존 대비 조합을 사용한다.
- 페이지별 새 색상을 임의로 추가하지 않는다. 필요한 예외는 사용자와 합의한다.

## 화면 검증 범위

- 화면 검증이 필요한지는 AGENTS.md로 판단하고, 필요한 경우에만 아래 수집 방법을 적용한다.
- 검증 항목은 AGENTS.md의 영향 기반 기준으로 선택한다. 예를 들어 섹션 순서만 옮기면 순서·내용 보존과 관련 구간의 데스크톱·모바일 배치를 확인하고, 그대로인 색상·이미지·링크 구현은 재검증하지 않는다.
- 같은 상태에서는 질문에 맞는 최소 증거를 선택한다. 문구·링크는 관련 DOM 구간, 시각적 배치는 해당 화면 캡처로 확인하고, 전체 접근성 트리와 스크린샷을 습관적으로 함께 반복 수집하지 않는다.
- 전체 페이지 캡처는 페이지 전체의 흐름이나 전체 레이아웃 변경을 확인해야 할 때만 사용한다.
- 확인한 결과는 작업 보고에 재사용한다. 별도 검토자가 필요한 경우에도 이미 통과한 결과를 전달하고, 실패나 추가 변경이 없으면 같은 화면을 재검증하지 않는다.
