# 업무 프로젝트

보이저엑스의 [Project R](../../../../src/content/projects/project-r.md)과 [Inspix World](../../../../src/content/projects/inspix-world.md)를 구분한다.

- Canva 원자료와 최신 사용자 정정을 대조하며 의미를 유지해 요약한다.
- 프로젝트의 구현 결과와 사용자 기여를 구분하고 실제 수행 범위를 설명한다.
- 두 프로젝트는 Unity 기반 3D 가상 공간의 메타버스 커뮤니티 게임이다. 카드 요약은 “나만의 아바타를 만들어 다양한 미니게임을 즐기며 친구를 사귀는 메타버스 소셜 게임”으로 통일하고, Unity · C#은 기술 태그로 표시한다.

## Project R

- 상세에서는 빌드 자동화, 이모트, 상점을 구분한다. 개인 빌드 환경과 세부 검증·운영 설명은 관련 구현 내용 가까이에 둔다.
- 이미 제거한 중복 GIF와 이모트·상점의 반복 회고를 다시 추가하지 않는다.
- 빌드 설명은 Unity의 모듈식 빌드·BuildProfile, Jenkins 자동화, Launcher 운영 순으로 구성한다. 요청자가 선택한 브랜치의 최신 소스를 반영하는 방식이며, 특정 커밋 지정 빌드로 표현하지 않는다.
- 전체 파이프라인 그림은 Jenkins 설명에, 빌드 옵션 화면은 BuildProfile 설명에 둔다. 빌드 회고와 개인 빌드 환경의 회고는 제외한다.
- UI는 R3와 MVVM으로 데이터와 화면의 역할을 분리한 의도를 설명하며, UniTask 언급은 제외한다.
- 공개 우려로 대표 미디어를 제외한 결정은 이 프로젝트에만 적용한다.

## Inspix World

- 라이브 이슈 대응·업데이트·테스트 환경·문서화·협업·온보딩의 기여 범위를 구분한다.
- 이슈 이미지는 공개 범위를 확인하고 비공개 정보를 가린 자료를 사용한다.
