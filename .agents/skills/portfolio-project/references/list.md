# 프로젝트 목록과 공유 카드

2026-11-10부터 AI를 본격 활용한 프로젝트(`aiCollaboration: true`)는 프로젝트 목록에서 빼 `AI 협업`(`/ai/`) 대분류에 둔다. AI 협업 페이지는 제목·소개·필터 없이 같은 카드 그리드와 미리보기를 쓴다([AI 협업 사양](../../../../docs/drafts/ai-section-spec.md)).

[프로젝트 목록](../../../../src/pages/projects/index.astro)의 탐색 기준이다. 프로필과 목록의 카드 공유·동기화 원칙은 [AGENTS.md](../../../../AGENTS.md)의 콘텐츠 기준을 따른다.

## 목록과 필터
- 분류의 순서·이름·필터 링크는 `src/config/projectGroups.ts`를 단일 원본으로 사용한다. 새 분류를 추가하면 목록 필터와 상단 프로젝트 하위 메뉴(hover·키보드, 터치 환경은 미표시)에 함께 반영한다. 메뉴에 별도 표기가 필요할 때만 `navLabel`을 사용하고, 기본값은 `label`을 따른다.
- 업무·게임·AI 활용·연구를 구획으로 나누지 않고 같은 높이 카드 그리드로 표시한다. 공통 폭 안에서 데스크톱 3열, 중간 폭 2열, 모바일 1열이다(2026-11-05 가로 스크롤에서 변경, 메이슨리는 시험 후 제외). 카드 내부는 이미지(고정 비율) → 제목(2줄 고정) → 소개(2줄 고정) → 태그(고정 높이) 구역으로 규격화해 같은 줄 카드의 구역 시작선을 맞춘다. 넘치는 글은 말줄임, 넘치는 태그는 접는다. 안내 문구와 자동 움직임은 추가하지 않는다.
- 전체·업무·게임·AI 활용·연구 버튼으로 같은 화면에서 필터링한다. AI 활용은 AI를 활용한 결과물과 협업 과정을 다루는 개인 프로젝트 분류다. 게임에는 업무 게임도 포함하며 카드 분류 스티커와 같은 기준을 사용한다.
- 필터는 URL 공유와 뒤로가기를 지원한다. 이전 분류별 목록 URL(`/projects/work·games·research/`)은 외부 공유 이력이 없어 연결 페이지를 두지 않는다(예외 처리, 2026-10-21). 외부에는 루트 주소만 공유한다.

## 카드 구성
- 카드는 대표 이미지(좌상단 분류 스티커), 프로젝트명, 짧은 소개 한 줄(`cardLabel`), 태그(기술 스택)만 표시해 작은 카드에서도 읽히게 한다. 태그는 핵심 기술 순으로 최대 4개이며, 에셋·작업 방식·AI 도구 이름은 태그로 넣지 않는다. 특징 문장·담당은 카드에 넣지 않고 상세·메타데이터에 둔다(2026-11-05 변경).
- 업무 게임에는 업무·게임 스티커를 함께 표시하며, 카드에 화살표를 추가하지 않는다.
- AI 협업 여부는 프로젝트 데이터 `aiCollaboration`으로 관리하며, 기준은 Project BFX(2026.05 시작)부터다. 해당 프로젝트는 `AI 협업` 대분류에 들어가므로 카드에 별도 'AI 협업' 표시는 하지 않는다(2026-11-10). 주제 분류 스티커는 그대로 둔다.
- 모서리 10px와 hover·focus 강조선 2px를 유지한다. 이미지 높이 등 실제 치수는 공통 카드 스타일에서 관리하며 과거의 증감 지시를 반복 적용하지 않는다.

## 이렇게 일합니다
- 페이지 맨 위(필터 위)에 캐릭터(말풍선 포함)와 능력치 장치를 두고, 구역 제목은 화면에 표시하지 않는다(접근성용으로만 유지). 필터·목록과는 구분선으로 나눈다.
- 모바일에서는 작은 캐릭터와 여섯 항목 2×3 칩(아이콘+이름)의 압축형으로 표시하고, 칩을 누르면 근거 미리보기를 연다. 능력치 여섯 칸은 아이콘과 짧은 이름(책임감·시야·개선과 실행·소통·협력·성장)을 항상 표시하고, 미리보기는 hover로 열지 않고 클릭·탭·Enter로만 열며, 미리보기 안의 링크로 근거 프로젝트에 연결한다(2026-11-05). 캐릭터는 첫 화면이므로 바로 불러온다.

## 미리보기(퀵뷰)
- 카드를 누르면 상세로 바로 가지 않고 미리보기 창을 연다(2026-11-05). 이미지(위) → 분류·제목·소개 한 줄·메타(기간·역할·팀 규모·플랫폼 중 있는 것)·요약·담당·주요 구현(최대 5개)·태그 → 하단 고정 '상세 보기'. 모바일은 아래에서 올라오는 시트.
- 주소 `?project=<id>`로 공유·뒤로 가기를 지원하고 `?filter=`와 공존한다. Esc·닫기·바깥 클릭·뒤로 가기로 닫히며 포커스는 연 카드로 돌아온다. JS가 없거나 보조키·가운데 클릭이면 상세로 바로 이동한다.
