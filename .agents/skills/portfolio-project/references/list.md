# 프로젝트 목록과 AI 협업 카드

`aiCollaboration: true`인 프로젝트는 AI 협업(`/ai/`) 목록에 둔다. 회사 업무 프로젝트의 공개 범위와 상세·요약 동기화는 [AGENTS.md](../../../../AGENTS.md)의 콘텐츠 기준을 따른다.

## 프로젝트 목록

- [프로젝트 목록](../../../../src/pages/projects/index.astro)은 커버 캐러셀과 프로젝트별 소개 블록 순서로 구성한다. 접근성용 h1은 화면에서 숨긴다.
- 캐러셀은 화면 폭을 넓게 쓰고 현재 커버 양옆에 이전·다음 커버의 일부를 보여 준다. 양옆 미리보기를 누르면 전환하며, 마우스를 올리거나 Tab으로 포커스하면 미리보기가 밝아지고 방향 표시가 나타난다. 680px 이하에서는 커버를 좌우로 밀어 전환한다. 하단 점 버튼과 키보드 좌우 키로도 전환할 수 있다. 현재 커버 하단 가운데에는 어두운 그라데이션 위에 분류, 제목, '자세히 보기'를 세로로 배치하고 커버 전체를 상세 링크로 연결한다. 슬라이드는 글과 함께 좌우로 이동하며 순환하고, 움직임 줄이기 설정에서는 밝기와 슬라이드가 즉시 전환한다.
- 소개 블록은 공통 본문 폭 안에서 큰 이미지 위에 글 카드를 겹친다. 각 블록의 이미지와 글 카드 위치는 좌우로 번갈아 배치한다. 680px 이하에서는 캐러셀에 한 장을 표시하고 소개 블록은 이미지, 글 카드 순으로 쌓는다.
- 글 카드에는 프로젝트명, 한 줄 소개(`cardLabel`, 없으면 `summary`), 핵심 기술 최대 4개, 상세로 연결하는 '자세히 보기'를 둔다. 둥근 모서리, 가는 테두리의 알약형 버튼, 넉넉한 블록 여백을 쓴다. 색과 포커스는 [공통 레이아웃](../../portfolio-layout/references/layout.md)을 따른다.
- 목록 진입 주소는 `/projects/`다. 기존 분류 쿼리를 붙여 방문해도 전체 목록을 표시한다.

## 이렇게 일합니다

- 2026-11-27부터 프로젝트 목록에서 숨긴다. `ProfileCharacter`와 `IntroHex`를 페이지 렌더링에서 제외해 모델과 스크립트 요청을 발생시키지 않는다. 컴포넌트와 관련 파일 및 에셋은 재사용할 수 있도록 보존한다.

## AI 협업 카드

- 작업 환경 구역 아래에 카드 그리드를 둔다. 데스크톱 3열, 중간 폭 2열, 좁은 화면 1열이며 각 카드의 이미지, 제목, 한 줄 소개, 기술 태그 시작선을 같은 줄에서 맞춘다. 1열에서는 글의 높이를 내용에 맞춘다.
- 카드에 대표 이미지와 좌상단 주제 분류 스티커, 프로젝트명, `cardLabel`(없으면 `summary`), 핵심 기술 태그 최대 4개를 표시한다. 모서리와 hover·focus 강조선은 공통 카드 스타일을 쓴다.
- 카드를 누르면 미리보기 창이 열린다. 대표 이미지, 분류, 제목, 소개, 메타데이터, 요약, 담당, 주요 구현(최대 5개), 태그, '상세 보기'를 표시한다. 모바일에서는 아래에서 올라오는 시트로 표시한다.
- 미리보기는 `?project=<id>`로 공유하거나 뒤로 이동할 수 있다. Esc, 닫기 버튼, 바깥 클릭, 뒤로 가기로 닫으며 포커스는 열었던 카드로 돌아온다. JS가 없는 환경이나 보조키·가운데 클릭에서는 상세로 바로 이동한다.
