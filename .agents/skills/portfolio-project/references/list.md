# 프로젝트 목록과 공유 카드

[프로젝트 목록](../../../../src/pages/projects/index.astro)의 탐색 기준이다. 프로필과 목록의 카드 공유·동기화 원칙은 [AGENTS.md](../../../../AGENTS.md)의 콘텐츠 기준을 따른다.

## 목록과 필터
- 분류의 순서·이름·필터 링크는 `src/config/projectGroups.ts`를 단일 원본으로 사용한다. 새 분류를 추가하면 목록 필터와 상단 프로젝트 하위 메뉴(hover·키보드, 터치 환경은 미표시)에 함께 반영한다. 메뉴에 별도 표기가 필요할 때만 `navLabel`을 사용하고, 기본값은 `label`을 따른다.
- 업무·게임·AI 활용·연구를 구획으로 나누지 않고 동등한 크기의 가로 스크롤 카드로 표시한다. 다음 카드의 약 15~20%와 하단 스크롤바로 탐색을 드러낸다. 별도 이전·다음 버튼, 안내 문구, 자동 움직임은 추가하지 않는다.
- 전체·업무·게임·AI 활용·연구 버튼으로 같은 화면에서 필터링한다. AI 활용은 AI를 활용한 결과물과 협업 과정을 다루는 개인 프로젝트 분류다. 게임에는 업무 게임도 포함하며 카드 분류 스티커와 같은 기준을 사용한다.
- 필터는 URL 공유와 뒤로가기를 지원하며 전환 시 가로 스크롤을 처음으로 되돌린다. 이전 분류별 목록 URL(`/projects/work·games·research/`)은 외부 공유 이력이 없어 연결 페이지를 두지 않는다(예외 처리, 2026-10-21). 외부에는 루트 주소만 공유한다.

## 카드 구성
- 대표 이미지, 프로젝트명, 특징 한 문장, 담당 한 줄, 기술 스택, 이미지 좌상단 분류 스티커를 표시한다. 특징·담당은 기존 프로젝트 데이터를 사용한다.
- 업무 게임에는 업무·게임 스티커를 함께 표시하며, 카드에 화살표를 추가하지 않는다.
- 모서리 10px와 hover·focus 강조선 2px를 유지한다. 이미지 높이 등 실제 치수는 공통 카드 스타일에서 관리하며 과거의 증감 지시를 반복 적용하지 않는다.
