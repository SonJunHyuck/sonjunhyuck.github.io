# 연구 프로젝트

연구 분류의 명칭을 사용하고 대표 미디어를 유지한다. 제공된 원본 자료를 우선한다.

- [Wind Map Simulation](../../../../src/content/projects/wind-map-simulation.md)의 Old는 사용자의 구버전이다. Mapbox WebGL 자료와 구분하고 외부 자료의 출처를 표시한다.
- [Crowd Formation Control](../../../../src/content/projects/crowd-formation-control.md)은 선행 연구와 사용자의 확장 기여를 구분한다.
- 시각적으로 확인한 동작을 정량 성능 개선으로 표현하지 않는다.
- 수치를 쓸 때 측정 결과·환경·근거를 확인한다.
