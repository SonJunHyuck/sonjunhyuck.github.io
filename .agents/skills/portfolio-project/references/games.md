# 게임 프로젝트

게임 분류를 개인 프로젝트로 한정하지 않는다. 팀 작업과 개인 기여를 구분한다.

## The Hidden Cheer Squad

[현재 상세](../../../../src/content/projects/the-hidden-cheer-squad.md)를 확인한다.

- 소개는 “밀려오는 적들을 막아내며, 적군을 물리치는 2D 전진형 디펜스 게임”을 기준으로 한다.
- 대표 미디어를 유지한다.

## Project BFX

[현재 상세](../../../../src/content/projects/bfx.md)를 확인하고 소개 → 구현의 흐름을 유지한다.

- 제목 아래 소개의 첫 문장만 강조색으로 표시하고, 본문의 중복 게임 소개는 두지 않는다. ‘구현 및 기여’ 카드와 기능 본문은 외부 대화 도구의 반복 편집 개선 → 퀘스트 시스템·대화 연동 → 알림 UI 순서로 소개한다. 카드는 Project R과 같은 공통 형식을 사용한다.
- 함께 의견을 나눈 일을 사용자의 기획 총괄로 확대하지 않는다. 기간은 현재 공란이며 근거 없이 채우지 않는다.
- 외부 Dialogue System의 기능과 사용자가 직접 구현한 확장을 구분한다.
- C# 퀘스트 시스템은 사용자가 직접 구현했다. Lua 기반 외부 대화 시스템과 연결하는 Bridge의 필요를 설명한다.
- 노드를 수작업으로 편집하는 부담과 시트 기반 임포터의 연결을 설명한다.
- 알림 창구가 필요한 이유와 호출 방식을 설명하고 확인·취소 결정을 받는 Popup은 구분한다.
- 별도의 AI 활용 섹션은 공개 상세에서 제외한다. AI 활용에 대한 경험과 관점의 변화는 사용자가 확인한 ‘마치며’ 회고에 담고, 관련 원본 자료는 보존한다.
- 판단의 배경을 확인할 때만 [DECISIONS.md](../../../../docs/project-materials/bfx/DECISIONS.md)를 읽는다.
- 실제 구현·변경 범위를 확인할 때만 [CODE_EVIDENCE.md](../../../../docs/project-materials/bfx/CODE_EVIDENCE.md)를 읽는다.
