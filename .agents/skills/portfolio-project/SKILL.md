# 프로젝트 편집

프로젝트 간 비슷한 정보 구조와 읽는 흐름을 지향한다. 사용자 지시가 있거나 더 효과적인 표현이 있으면 이유와 구성을 제안하고 합의한 내용을 적용한다. 공통 정책과 상세·카드 동기화는 [AGENTS.md](../../../AGENTS.md)를 따른다.

- 강조는 개선 의도(왜)와 구현 방법(어떻게)을 우선한다. 결과만 강조하거나 문단 전체에 강조색을 적용하지 않는다.
- 원본 미디어를 우선하고 관련 설명 가까이에 배치한다. 화면에서 제외해도 원본을 삭제하지 않는다.
- 공개 캡션은 장면·구현 내용을 설명하며, 요청하지 않은 재생 시간·무음 여부·검수 메모는 넣지 않는다.
