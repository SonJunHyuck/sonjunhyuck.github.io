# 프로젝트 편집

프로젝트 간 비슷한 정보 구조와 읽는 흐름을 지향한다. 사용자 지시가 있거나 더 효과적인 표현이 있으면 이유와 구성을 제안하고 합의한 내용을 적용한다.

- 대상의 변경 구간을 확인하고 작성 기준이 필요할 때 해당 매뉴얼의 대상 프로젝트 절만 읽는다. 의미를 유지한 오탈자·띄어쓰기 수정은 매뉴얼을 추가로 읽지 않는다.
- 사실·역할·성과를 추가하거나 바꾸거나 기존 내용과 충돌할 때 원자료와 최신 합의를 대조한다. 의미를 유지한 표현 수정에는 원자료를 재조회하지 않는다.
- 제공된 원본 미디어를 우선하고 관련 설명 가까이에 배치한다. 화면에서 제외하는 결정은 원본 삭제를 뜻하지 않는다.
- 상세 수정에 따른 카드 요약·메타데이터 갱신, 공통 정책과 검증 범위는 [AGENTS.md](../../../AGENTS.md)를 따른다.
- 구현 위임은 AGENTS.md의 모델 규칙을 따른다. 구현 담당자는 같은 작업을 재위임하지 않는다.
- 배치·스타일·반응형 변경 또는 구체적인 화면 문제 해결에만 [portfolio-layout](../portfolio-layout/SKILL.md)을 함께 적용한다.
