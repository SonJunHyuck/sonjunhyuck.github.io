# 자기소개

현재 프로필은 [profile/index.astro](../../../../src/pages/profile/index.astro)에 있다.

- 프로필은 사용자의 기본을 보여 주는 이력서형 페이지다. 맨 위에 본문 전체 폭의 좌우명을 두고, 그 아래 사진(`/profile.webp`) 왼쪽과 기본 정보 오른쪽을 나란히 배치한다. 모바일에서도 작은 사진과 옆 정보를 유지한다. 기본 정보는 손준혁, SON JUNHYUCK, 게임 클라이언트 개발이며 기존 버튼 스타일의 '포트폴리오 PDF 다운로드'를 둔다. 다운로드 경로는 `/files/son-junhyuck-portfolio.pdf`, 저장 이름은 `손준혁_포트폴리오.pdf`다. eyebrow와 숨김 h1은 유지한다(2026-11-23 개편). 이어서 업무 경험·학력·활동, 마지막에 하이라이트·프로젝트로 가는 큰 버튼과 연락 링크를 둔다.
- 3D 캐릭터와 능력치 장치는 프로필에 두지 않고 프로젝트 목록 아래 '이렇게 일합니다' 구역에 둔다.
- 맨 위 문구는 자기소개가 아닌 좌우명이다. 좌우명은 데이터 파일 하나에 모아 두고(강조 단어는 `**단어**`) 페이지에 들어올 때 무작위로 1개만 보여 준다. 버튼·라벨·자동 전환은 두지 않는다. 폰트는 Song Myung(400)을 프로필 좌우명에만 쓴다(2026-11-23 사용자 지정, Gaegu에서 교체). 사용자의 생각이므로 근거나 설명 문구를 덧붙이지 않는다(2026-11-14, 이전 “부딪히고, 설계합니다.” 대체).
- 좌우명은 데스크톱에서 두 문구 모두 한 줄로 표시하고, 좁은 화면에서는 자연스럽게 줄바꿈한다. `text-wrap: balance`나 강제 `br`로 나누지 않는다(2026-11-23).
- 자기소개 아래에 별도 근거 링크는 두지 않는다(2026-11-05 제거). 근거는 업무 경험의 키워드 카드 링크로 연결한다. 상세 구현 설명을 프로필에 반복하지 않는다.
- 프로필에 독립된 기술 스택 영역을 두지 않는다. 업무별 기술 태그와 프로젝트의 기술 정보로 확인할 수 있게 한다.
- 업무 경험 하단의 “문제에 맞는 도구를 선택합니다” 관점과 두 사례 블록은 제거한 구성을 유지한다.
