# 자기소개

현재 프로필은 [profile/index.astro](../../../../src/pages/profile/index.astro)에 있다.

- 프로필은 이력서형 페이지다. 공통 페이지 배경 위에 기존 사진(`/profile.webp`)을 원형으로 배치하고 이름(h1), 직무, 연락처를 중앙에 둔다. 아래에 '팀의 작업에 세이브 포인트를 만듭니다.' 자기소개를 두고 업무 경험, 학력, 활동을 잇는다. 2026-11-27 개편에서 좌우명과 포트폴리오 PDF를 제거했다.
- 페이지 끝의 CONNECT에는 GitHub, Notion, Canva, 이력서 링크를 둔다. 이력서 링크에는 서핏 공식 아이콘을 사용하며 주소는 `src/config/links.ts`에서 공통 푸터와 함께 관리한다. 이 링크들과 수상 관련 기사 버튼의 화살표를 제거했다(2026-11-27).
- 3D 캐릭터와 능력치 장치는 프로필에 두지 않고 프로젝트 목록 아래 '이렇게 일합니다' 구역에 둔다.
- 자기소개 아래에 별도 근거 링크는 두지 않는다(2026-11-05 제거). 근거는 업무 경험의 키워드 카드 링크로 연결한다. 상세 구현 설명을 프로필에 반복하지 않는다.
- 프로필에 독립된 기술 스택 영역을 두지 않는다. 업무별 기술 태그와 프로젝트의 기술 정보로 확인할 수 있게 한다.
- 업무 경험 하단의 “문제에 맞는 도구를 선택합니다” 관점과 두 사례 블록은 제거한 구성을 유지한다.
