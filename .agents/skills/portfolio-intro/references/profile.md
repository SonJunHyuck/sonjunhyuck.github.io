# 자기소개

현재 프로필은 [index.astro](../../../../src/pages/index.astro)에 있다.

- 자기소개를 중심으로 사진·직무·연락 링크를 함께 읽을 수 있게 구성한다.
- “부딪히고, 설계합니다.”는 직접 경험하며 문제를 이해하고 반복 작업의 자동화를 추구한다는 맥락으로 설명한다.
- Project R의 빌드·배포 자동화와 BFX의 대화 데이터 임포터를 소개의 근거로 연결한다. 상세 구현 설명을 프로필에 반복하지 않는다.
- 소개의 근거 카드는 프로젝트 목록을 재사용하는 프로젝트 카드와 역할이 다르다. 연결한 상세가 바뀌면 근거 문구도 확인한다.
- 외부 첨삭의 3줄 소개나 기술 스택의 하단 이동을 확정된 구성으로 간주하지 않는다.

- 프로필에 독립된 기술 스택 영역을 두지 않는다. 업무별 기술 태그와 프로젝트의 기술 정보로 확인할 수 있게 한다.
- 업무 경험 하단의 “문제에 맞는 도구를 선택합니다” 관점과 두 사례 블록은 제거한 구성을 유지한다.
