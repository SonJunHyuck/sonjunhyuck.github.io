# 자기소개

현재 프로필은 [index.astro](../../../../src/pages/index.astro)에 있다.

- 프로필은 사용자의 기본을 보여 주는 이력서형 페이지다. 맨 위에 자기소개 문구와 사진(`/profile.webp`)을 두고, 그 아래 업무 경험·학력·활동, 마지막에 프로젝트·피드로 가는 큰 버튼과 연락 링크를 둔다(2026-11-05 개편).
- 3D 캐릭터와 능력치 장치는 프로필에 두지 않고 프로젝트 목록 아래 '이렇게 일합니다' 구역에 둔다.
- “부딪히고, 설계합니다.”는 직접 경험하며 문제를 이해하고 반복 작업의 자동화를 추구한다는 맥락으로 설명한다.
- 자기소개 아래에 별도 근거 링크는 두지 않는다(2026-11-05 제거). 근거는 업무 경험의 키워드 카드 링크로 연결한다. 상세 구현 설명을 프로필에 반복하지 않는다.
- 프로필에 독립된 기술 스택 영역을 두지 않는다. 업무별 기술 태그와 프로젝트의 기술 정보로 확인할 수 있게 한다.
- 업무 경험 하단의 “문제에 맞는 도구를 선택합니다” 관점과 두 사례 블록은 제거한 구성을 유지한다.
