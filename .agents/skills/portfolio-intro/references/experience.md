# 경력

[index.astro](../../../../src/pages/index.astro)의 회사·직무·기간과 회사별 프로젝트를 확인한다. 기간 값을 이 매뉴얼에 복사해 관리하지 않는다.

- 보이저 경력은 Project R과 Inspix World의 기여를 구분한다.
- 구현·운영·협업·문서화 중 실제 수행한 범위를 분명히 표현한다.
- 경력에는 역할과 핵심 기여를 요약하고 프로젝트 상세로 연결한다. 상세의 구현 설명을 반복하지 않는다.
- 기여 항목은 키워드 카드로 표시한다: Lucide 아이콘 + 키워드 제목 + 기존 한 줄. 상세가 있으면 키워드 제목 자체를 링크로 하고 '근거 보기' 같은 별도 문구는 두지 않는다. 모든 경력에 같은 형식을 쓴다(2026-11-05).
- 키워드는 세부 기능이 아니라 업무 영역 수준으로 넓게 잡는다(예: 빌드·배포, 인게임 콘텐츠 (감정표현), UI, 라이브 서비스 운영, 협업·조율, 문서화, 게임플레이, 최적화).
- 경력 수정이 프로젝트 설명과 충돌하면 원자료와 최신 사용자 정정을 대조한다.
