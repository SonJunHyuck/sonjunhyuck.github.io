# 학력과 활동

현재 정보는 [프로필](../../../../src/pages/index.astro)에서 관리한다. 학위·연구 실적·수상·자격을 구분하며, 날짜와 상태를 이 매뉴얼에 복사하지 않는다.

## 학력과 연구 실적
- 학교·전공·학위·기간·졸업 상태를 확인하고, 학위 취득 시점과 논문 게재 시점을 구분한다.
- 연구는 학력과의 연관성을 요약하고 논문·연구 프로젝트로 연결한다. 상세 설명을 반복하지 않는다.

## 수상과 자격
- 수상명·대회명·수상 시점과 자격명·취득 시점을 구분해 작성한다.
- 팀의 수상 결과와 사용자의 기여를 구분하고, 자격 보유를 실무 숙련도로 확대하지 않는다.
- 활동의 의미를 짧게 설명하고 근거로 연결한다. 새 활동은 성격에 맞게 분류한다.
