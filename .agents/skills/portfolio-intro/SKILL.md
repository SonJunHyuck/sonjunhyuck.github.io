# 프로필 편집

핵심 소개와 경험을 요약하고 상세 근거로 연결한다. 공통 정책은 [AGENTS.md](../../../AGENTS.md)를 따르며, 작성 기준이 필요한 항목의 매뉴얼만 읽는다.

## 매뉴얼 선택
- 자기소개·사진·링크: [profile.md](references/profile.md)
- 회사와 프로젝트별 경력: [experience.md](references/experience.md)
- 경험의 회고와 상세 연결: [reflection.md](references/reflection.md)
- 프로필에 노출하는 프로젝트: [project-cards.md](references/project-cards.md)
- 학위·연구 실적·수상·자격: [credentials.md](references/credentials.md)의 해당 절

배치·스타일·반응형 변경이나 화면 문제를 다룰 때는 [portfolio-layout](../portfolio-layout/SKILL.md)을 함께 적용한다.
