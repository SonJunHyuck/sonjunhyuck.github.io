# 프로필 편집

핵심 소개와 경험을 읽기 쉽게 요약하고, 상세 근거로 연결한다.

- 대상의 변경 구간을 확인하고 작성 기준이 필요할 때 해당 매뉴얼만 읽는다. 의미를 유지한 오탈자·띄어쓰기 수정은 매뉴얼을 추가로 읽지 않는다.
- 사실·역할·성과를 추가하거나 바꾸거나 기존 내용과 충돌할 때 원자료와 최신 합의를 대조한다. 의미를 유지한 표현 수정에는 원자료를 재조회하지 않는다.
- 공통 콘텐츠·레이아웃 정책, 구현 위임과 검증 범위는 [AGENTS.md](../../../AGENTS.md)를 따른다. 구현 담당자는 같은 작업을 재위임하지 않는다.
- 배치·스타일·반응형 변경 또는 구체적인 화면 문제 해결에만 [portfolio-layout](../portfolio-layout/SKILL.md)을 함께 적용한다.

- 경험의 회고와 상세 연결: [reflection.md](references/reflection.md)

- 학위와 연구 실적: [education.md](references/education.md)
