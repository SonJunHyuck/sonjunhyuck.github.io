# 프로필 편집

핵심 소개와 경험을 읽기 쉽게 요약하고, 상세 근거로 연결한다.

- 대상과 현재 본문을 먼저 확인하고 아래에서 해당 매뉴얼만 읽는다.
- 원자료와 최신 합의를 대조하고, 수정 이유·제안 문구·미확인 내용을 구분한다.
- 공통 콘텐츠·레이아웃 정책과 구현 위임은 [AGENTS.md](../../../AGENTS.md)를 따른다. 구현 담당자는 같은 작업을 재위임하지 않는다.
- 화면을 변경할 때 [portfolio-layout](../portfolio-layout/SKILL.md)을 함께 적용한다.

## 매뉴얼 선택

- 자기소개·사진·기술·링크: [profile.md](references/profile.md)
- 회사와 프로젝트별 경력: [experience.md](references/experience.md)
- 경험의 회고와 상세 연결: [reflection.md](references/reflection.md)
- 프로필에 노출하는 프로젝트 카드: [project-cards.md](references/project-cards.md)
- 학위와 연구 실적: [education.md](references/education.md)
- 수상과 자격: [activities.md](references/activities.md)
