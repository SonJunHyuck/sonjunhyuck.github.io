# 피드 글 선별과 작성

## 원본
- 피드 원본: Notion 노트 데이터베이스에서 웹에 공개된 개발 관련 노트. '개발 피드' 영역(https://app.notion.com/p/sonnysmile/409ed1cbaf6c80828e80f10bfa0eb571)에 연결된 노트는 사용자가 지정한 후보이고, 연결되지 않은 노트도 선별해 후보로 제안할 수 있다(2026-10-31 확정).
- 개인 생활·구직 등 개발과 무관한 노트는 공개 상태여도 대상이 아니다. 이미 게시한 노트는 피드 글의 `notionUrl`로 구분한다.

## 제외 기준
후보 노트라도 다음에 해당하면 글로 만들지 않고, 제외한 노트와 이유를 보고한다.
- 원문이 링크·사진 위주이고 사진 주석(캡션)까지 합쳐도 사용자의 정리·생각이 거의 없어, 요약하려면 내용을 지어내야 하는 경우.
  - 예: 「당근은 왜 LLM Router를 직접 만들었을까?」 발표 메모는 영상 링크와 "몰라서 물어봄" 주석뿐이라 제외했다(2026-10-27).
- 공개할 수 없는 정보(회사 자료, 타인 식별 정보, 내부 수치)를 빼면 남는 내용이 없는 경우.

원문이 얇더라도 사진 주석에 설명이 있으면 그 내용을 근거로 쓴다. 판단이 애매하면 만들지 말고 사용자에게 묻는다.

## 작성
- 어조: 사용자 본인의 기록이므로 존댓말 없이 명사형으로 끝낸다(예: "~정리함", "~검토", "~로 전환"). 같은 어미가 매 줄 반복되지 않게 한다.
- 본문은 원문 사실만으로 3~5줄. 원문에 없는 성과·수치·해석을 더하지 않고, 반려·검토 중인 구상을 완료로 쓰지 않는다. 발표·강연 정리는 발표자의 사례와 사용자의 생각을 구분한다.
- 제목은 원문 제목을 쓰거나 의미를 유지해 짧게 다듬는다. 방문자가 모르는 약칭은 풀어 쓴다.
- 날짜: 본문에 적힌 날짜를 우선하고, 없으면 Notion 페이지 생성일을 쓴다.
- 태그: 고정 목록에서 1~2개만 고른다. 새 태그가 필요하면 만들지 말고 사용자에게 제안한다(2026-10-27 확정).

  | 태그 | 쓰는 글 |
  |---|---|
  | AI 활용 | AI 도구·협업이 주제인 글 |
  | 학습 기록 | 강연·밋업·영상·강의를 정리한 글 |
  | 개발 환경 | 작업 환경·도구·원격 접속 구성 |
  | 공모전 | 공모전 참가 정보와 출품 기획 |
  | 아이디어 | 구상·검토 중이거나 채택하지 않은 아이디어 |
  | 회고 | 내 작업 방식·경험을 돌아본 글 |
  | 군중 시뮬레이션 | 군중 시뮬레이션 연구·구현 기록 |
  | PBD | 위치 기반 동역학(Position-Based Dynamics) 알고리즘 관련 글 |

  목록의 단일 원본은 사이트 설정 파일이며, 목록에 없는 태그는 빌드에서 거부된다.
- 사진: 원문 그림 중 대표 1장을 `src/assets/feed/`에 저장해 쓴다. Notion 이미지 주소는 만료되므로 직접 링크하지 않는다. 그림 안의 공개 불가 정보는 위 제외 기준과 같이 판단한다.
