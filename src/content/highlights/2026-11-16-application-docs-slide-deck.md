경력기술서·포트폴리오 요약본을 만들며 HTML 인쇄 페이지에서 claude.ai 슬라이드 덱으로 전환. 부분별 코멘트와 직접 편집으로 수정을 주고받기 위함.
쪽 단위 수정은 쪽마다 Codex를 하나씩 띄워 병렬 처리하고, 덱 전체 공통 변경은 Claude가 직접 맡음. Codex마다 별도 herdr 탭을 두어 화면 공간 부족 문제 해결.
어두운 테마는 개발용, 애플 홈페이지 색 체계를 참고한 밝은 테마는 제출용으로 분리 운영.
디자인은 Spotify 앨범 페이지 콘셉트에서 출발해 프로젝트 색 그라데이션 헤더 대신 유형 라벨 글자색으로 구분하도록 단순화.
