# AI 협업 대분류 사양 (1차)

2026-11-10 사용자와 Claude가 합의한 내용이다. 첫 화면(카드 랜딩) 작업이 끝난 뒤 이어서 구현한다.

## 목적
- AI를 본격적으로 활용해 개발한 프로젝트(`aiCollaboration: true`, 현재 Project BFX·AI 협업 포트폴리오)를 프로젝트 목록에서 분리해 별도 대분류로 보여 준다.

## 주소와 메뉴
- 이름 'AI 협업', 주소 `/ai/`.
- 메뉴는 `프로필 / 프로젝트 / AI 협업` 순서다. 개발일지는 푸터의 Notion 아이콘에서 연다(2026-11-26).
- 첫 화면 카드에 'AI 협업'을 추가한다. 이미지는 AI 협업 목록 순서상 첫 카드의 대표 이미지로 자동 결정한다. 한 줄 소개 초안: "AI와 함께 만든 프로젝트".
- 슬라이드인 흐름은 프로필 → 프로젝트 목록 → AI 협업 → 프로필이다. 상세의 '다음 프로젝트'는 같은 대분류 안에서 순환한다.

## 화면
- 카드 위에 사진·짧은 설명·관련 하이라이트 링크로 구성한 작업 환경 구역을 둔다(접근성용 h1은 숨김, 2026-11-23).
- 카드 그리드를 쓰며 카드를 누르면 미리보기 창이 열린다. 필터는 프로젝트가 늘어 필요해지면 추가한다.

## 프로젝트 목록 정리
- AI 협업 프로젝트는 `/ai/`에 둔다. 프로젝트 목록의 구성은 [목록 매뉴얼](../../.agents/skills/portfolio-project/references/list.md)을 따른다.
- 프로필 업무 경험·능력치 미리보기 등에서 BFX·포트폴리오로 가는 링크는 상세 주소가 그대로이므로 유지한다.
