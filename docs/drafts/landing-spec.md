# 첫 화면(카드 랜딩) 사양 (1차)

2026-11-10 사용자와 Claude가 합의한 내용이다. 구현은 Codex가 맡고 Claude가 검토한다.

## 목적
- 사이트 첫 화면(`/`)에서 대분류 페이지를 카드로 보여 주고, 방문자가 골라 들어가게 한다. 하스스톤의 손에 쥔 카드처럼 방사형(부채꼴)으로 펼친다.
- 카드: 프로필, 하이라이트, 프로젝트. 대분류가 늘면 카드를 추가한다(데이터 한 곳에서 관리).

## 주소
- 첫 화면은 `/`. 기존 프로필은 `/profile/`로 옮긴다. 외부에는 루트 주소만 공유했으므로 연결 페이지는 두지 않는다.
- 사이트 안의 프로필 링크(헤더 메뉴, 슬라이드인 행선지, 회고의 '프로필의 업무 경험으로' 등 `/`·`/#experience`)를 `/profile/` 기준으로 바꾼다. 헤더 로고는 첫 화면(`/`)으로.
- 헤더 메뉴는 그대로 `프로필 / 하이라이트 / 프로젝트 / 개발일지 ↗`. 첫 화면은 메뉴 항목이 아니다.

## 카드
- 다른 카드와 같은 구성: 위 이미지, 아래 제목과 한 줄 소개.
- 이미지(2026-11-10 변경): 프로필 = `/profile.webp`. 프로젝트 = 프로젝트 목록 순서상 첫 카드의 대표 이미지, 하이라이트 = 가장 최근 하이라이트 중 이미지가 있는 것의 썸네일. 빌드 시 데이터에서 자동으로 정해지므로 새 프로젝트·하이라이트가 생기면 따로 손대지 않아도 바뀐다.
- 한 줄 소개(초안): 프로필 "이력과 경험" / 하이라이트 "작업의 핵심 장면을 짧게" / 프로젝트 "프로젝트 전체 이야기".

## 동작
- 카드를 누르면 미리보기 없이 해당 페이지로 이동한다. 이동 순간 누른 카드가 커지며 다음 페이지로 이어지는 전환 연출(Astro View Transitions 등)을 넣는다.
- 처음 들어오면 손에 쥔 카드가 펼쳐지는 등장 연출.
- 데스크톱(hover 가능): 마우스를 올린 카드가 들려 올라오고 나머지는 살짝 비켜난다. 클릭으로 이동.
- 모바일(터치): 좌우로 밀어 부채를 돌리면 가운데 카드가 들려 올라온다. 가운데 카드를 탭하면 이동(가운데가 아닌 카드를 탭하면 그 카드를 가운데로).
- 키보드: Tab 포커스가 간 카드가 hover와 같이 들려 올라오고 Enter로 이동. 카드는 링크로 두어 JS 없이도 이동 가능.
- 움직임 줄이기 설정이면 등장·전환 연출 없이 정적인 부채꼴.
- 기존 색 변수만 사용, Light·Dark 대비.
