## 시각자료 제안

1. 협업 방식 전후 비교: 초기 ‘사용자 ↔ 논의 채팅 → 별도 구현 채팅’, 이후 ‘사용자 ↔ 논의 담당 → 구현 서브 에이전트 → 결과 공유’. 같은 저장소를 사용했다는 주석. 작업 맥락 분리·모델별 역할 지정 인용을 가까이 배치.
2. 공통 규격 구조도: AGENTS.md(공통 원칙) → 레이아웃 스킬(적용 흐름) → 공통 스타일(폭·색상 등의 값), 분야별 스킬 → 세부 매뉴얼(예외). 공통 레이아웃 필요 인용과 함께 배치. 과거 화면 캡처 없이 레이아웃 전후를 실제 스크린샷처럼 재현하지 않는다.
3. Router 후속 계획: 요청 → 모델 선택·예상 사용량 → 실행 → 실제 사용량·결과 기록 → 차이 분석 → 선택·실행 규칙 조정. ‘후속 프로젝트 구상 / 미구현’을 명시. 실제 절감 차트는 현재 제외.

대화는 긴 캡처보다 짧은 원문 발췌 카드와 날짜·채팅명을 권장한다. 발췌 카드라는 표기를 두며 원본 UI 캡처인 것처럼 만들지 않는다. 본문에는 핵심 3~4개만 쓰고 나머지는 보조 근거로 둔다.
