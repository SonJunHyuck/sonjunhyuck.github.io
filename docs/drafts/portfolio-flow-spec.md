# 포트폴리오 흐름 개편 사양 (논의 중)

2026-11-05 사용자와 Claude가 논의 중인 내용이다. 확정 전이며, 구현은 Codex가 맡고 Claude가 검토한다.
확정되면 영향받는 지침(AGENTS.md, portfolio-layout·portfolio-project 매뉴얼, feed-page-spec)을 함께 갱신한다.

## 취지
- 방문자는 사용자를 모른다. 쉽게 읽히고 직관적이어야 하며, 페이지를 넘나들어도 흐름을 잃지 않게 다음 행선지를 계속 제공한다.
- 흐름: 프로필(0) → 프로젝트(1) → 피드(2). 번호는 내부 인덱스이며 화면 메뉴에는 표시하지 않는다.

## 확정
- 프로필은 사용자의 기본을 보여 주는 이력서형 페이지: 맨 위 사진 + 자기소개 문구, 그 아래 경력·학력·활동.
- 캐릭터와 능력치(여섯 가지 태도 장치)는 프로젝트 페이지로 옮긴다. 프로젝트 목록 우선 원칙은 이에 맞춰 조정한다(위치 미정).
- 업무 경험의 기여 항목은 카드로 도식화: 아이콘 + 키워드 + 기존 한 줄 + 근거 프로젝트 링크. 모든 경력에 같은 형식.
- 프로필의 대표 프로젝트 카드는 제거하고, 프로젝트·피드로 가는 큰 버튼을 둔다.
- 좌우 화살표 이정표는 넣지 않는다(2026-11-05 제외).
- 페이지 하단에 도달하면 다른 페이지로 가는 작은 카드가 떠오르게 한다(슬라이드인 카드).
- 프로젝트 카드를 누르면 바로 이동하지 않고 개요 미리보기(퀵뷰 모달)를 띄운다. 모델별 탭 없이 클릭한 프로젝트의 개요만, '상세 보기'로 상세 페이지 이동.

## 읽기 흐름 검토 (2026-11-05, 배포 빌드 캡처: artifacts/review/2026-11-05/)
우선순위 높음
1. 페이지 끝에서 흐름이 끊김: 프로젝트 상세·회고·피드 끝에 다음 행선지가 없고 푸터(GitHub)만 있음. → 하단 슬라이드인 카드, 상세 끝 '다음 프로젝트·목록으로'.
2. 프로젝트 목록이 한 줄 가로 스크롤이라 데스크톱에서 약 2.3장만 보이고 전체 개수·구성을 알 수 없음. 화면 아래는 비어 있음. → 데스크톱 그리드 전환 검토(현재 가로 스크롤 원칙 변경 필요).
3. 프로필 첫 화면의 능력치 장치는 아이콘만 있어 의미가 hover 전에는 보이지 않고, 터치 환경에서는 알기 어려움. 모바일에서는 장치가 화면 한 개를 차지해 업무 경험이 약 1,000px 아래로 밀림. → 확정 사항(프로필은 사진+자기소개, 장치는 프로젝트 쪽으로)으로 해소하되, 옮길 때 항목 이름을 항상 보이게.
4. 업무 경험 기여가 글머리 목록뿐. → 확정 사항(키워드 카드)으로 해소.

보통
5. 프로젝트 상세가 길고(데스크톱 약 7,500px) 중간에 위치를 알 수 없음. → 넓은 화면에서 섹션 목차(고정) 검토.
6. 회고 제목이 강조색 부제와 한 줄로 이어져 '프로/젝트'처럼 단어 중간에서 줄바꿈됨. 본문 강조(파란 굵은 글씨)가 많아 강조 효과가 약함.
7. 피드의 Sonny Ghostty 사진은 터미널 글자가 작아 카드 크기에서 읽히지 않음. → 사이드바 부분 위주로 자르기 검토.
8. 프로젝트 카드 대표 이미지(포트폴리오 웹사이트)가 문구가 잘린 채 보임.
9. 모바일 업무 경험의 기간 줄 정렬이 어긋남(재직 기간 줄 들여쓰기).

## 구현 단계
- A: 프로젝트 목록 그리드 시안, p4 이미지 후보.
- B: 프로필 개편(사진+자기소개, 업무 경험 키워드 카드, 프로젝트 카드 제거, 프로젝트·피드 버튼), 캐릭터·능력치를 프로젝트 페이지로 이동(목록 아래, 항목 이름 표시).
- C: 흐름 장치(하단 슬라이드인 카드, 프로젝트 퀵뷰 모달, 상세 끝 다음 프로젝트·목록으로). 좌우 화살표는 제외.
- D: 상세 게이지 바, 회고 제목·강조 정리, 모바일 기간 줄 정렬, 카드 이미지 교체.
